# Personal Skills

Niche workflows specific to my use cases, installed system-wide

## Install

Install skills from this category:

```bash
npx skills@latest add https://github.com/Skarian/skills/tree/main/skills/personal --global
```

This command uses interactive skill and agent selection. See [My Setup](../../README.md#my-setup) for my five-agent preset.

Update installed personal skills with `npx skills@latest update -g`.
